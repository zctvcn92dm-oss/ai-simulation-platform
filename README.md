# AI模拟演练原型

这是一个零依赖、可直接运行的交互原型，覆盖：

- 学生工作台与师范生模拟试讲入口
- 成长赛道、就业赛道职规赛训练配置
- PPT模拟上传、材料版本和赛前诊断
- 摄像头/麦克风/PPT设备检测状态
- PPT陈述、倒计时与翻页状态
- 五位AI评委主问、追问与角色切换
- 证据化训练报告、历史记录与专项训练
- 全过程模拟回放、事件时间轴与逐题回答视频复盘
- 表情、仪态、言语、内容和临场应变的独立训练分析
- 录制授权说明、180天保留策略和受控视频权限示例
- 教师任务、学生报告和班级共性问题
- 桌面、平板和移动端响应式布局

## 启动

使用 Node.js：

```powershell
node serve.js
```

浏览器访问 `http://127.0.0.1:5317`。

本原型不上传真实PPT，也不调用真实摄像头、麦克风或AI接口；相关能力使用本地状态模拟，以便验证完整产品流程。
